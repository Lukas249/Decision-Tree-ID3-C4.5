# ID3 / C4.5 Decision Tree Classifier

A from-scratch Python implementation of decision tree learning algorithms (**ID3 / C4.5**) for multi-class classification on categorical datasets.

## Splitting Criteria & Metrics

To determine the optimal attribute for splitting the dataset at each node, the algorithm calculates and evaluates the following metrics:

* **Shannon Entropy:** Measures the impurity or randomness of class labels within a subset.
* **Information Gain:** Computes the expected reduction in entropy achieved by partitioning the dataset on a given attribute.
* **Split Information:** Measures the potential information generated by splitting the dataset into $n$ subsets (penalizing attributes with a large number of distinct values).
* **Gain Ratio (C4.5):** Normalizes Information Gain by dividing it by Split Information (`Gain Ratio = Information Gain / Split Information`) to select the best split without bias toward multi-valued attributes.

## Dataset Format

Input files should be headerless CSV/TXT files with comma-separated values, where **the final column denotes the target decision class**.

**Example (`test.txt`):**
```text
sunny,hot,high,weak,no
sunny,hot,high,strong,no
overcast,hot,high,weak,yes
rain,mild,high,weak,yes
```
